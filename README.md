# Instagram Profile Card Hover Effect 🔍💼

A stylish and interactive **Instagram-style profile card** with hover effects, built using **HTML** and **CSS**. Perfect for showcasing user profiles in portfolio websites or social media mockups.

## 🔗 Live Demo

[View Live](https://prakashrpk.github.io/insta-profile-card-hover-effect/)  

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (for animations and hover effects)
- **Font Awesome** (for social icons)

---

## ✨ Features

- Elegant profile card UI
- Smooth hover transition revealing user info
- Profile picture and Instagram-like layout
- Responsive and lightweight design
